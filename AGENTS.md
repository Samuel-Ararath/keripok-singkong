# Project guide

Northstar is a TanStack Start React dashboard. The landing route lives in `src/routes/index.tsx`; global typography, layout, responsive behavior, and component styling live in `src/styles.css`. Head metadata is defined in `src/routes/__root.tsx`.

The dashboard currently uses local presentation data so the interface can be explored without setup. Keep the visual language restrained: warm off-white surfaces, indigo accents, Manrope headings, and DM Sans body copy. Preserve keyboard-accessible buttons and the mobile navigation behavior when extending the UI.
